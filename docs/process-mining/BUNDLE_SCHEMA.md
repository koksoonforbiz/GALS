# Session bundle schema (v2)

The research export (`tools/gals-export`) writes one bundle per session: a folder (or zip) with `manifest.json`, `session.json`, JSONL streams, replay snapshots and webcam segments. GALS Studio imports it. The byte-level layout, integrity rules and v1 streams are in `tools/gals-export/BUNDLE_SPEC.md`. This page lists what **v2** (2026-11-26, Prompt B phase 7) adds.

## Compatibility

- `manifest.bundleVersion` is `2`; `exporterVersion` is `2.0.0`.
- Every v1 file and every v1 field is kept, so a v1 reader still loads a v2 bundle and ignores the new files. GALS Studio accepts `bundleVersion` 1 and 2 (`SUPPORTED_BUNDLE_VERSIONS`), imports the v1 files and ignores the rest until Prompt C models them.
- New files are optional: they are left out when empty, and they never set the session's duration (`UNTIMED_STREAMS`).
- Rows from mapped tables keep their database column names (snake_case); rows from the interaction streams keep camelCase. BigInt becomes a number, timestamps become ISO strings, and every row has a `wallMs` for ordering.

## Consent

Text fields (chat, typed answers, keystroke and clipboard text, Prompt Lab prompts and outputs, reflections) are included: consent is collected on the study consent form before a learner joins. With `TEXT_CONSENT_IN_APP=true` the export again follows each learner's research-use decision.

## New and extended content

| File                                                            | What                                                                                                                                                                                                                                                               | Scope   |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------- |
| `session.json`                                                  | adds `closeReason`, `paramsVersion`, `previousSessionId`, `episodeKey`, `clockOffsetMs`                                                                                                                                                                            | session |
| `streams/activity.jsonl`                                        | adds the row `id` and the envelope: `clientEventId`, `clientSeq`, `tabId`, `serverReceivedMs`, `durationMs`, `sourceChannel`, `appBuild`, `consentScope`, `slideKey`, `objectId`, `contentVersion`, `qualityCode`, and `assessmentId` / `attemptId` / `questionId` | session |
| `streams/keystrokes.jsonl`                                      | adds the typed burst: `keys` (`{k, t}` with ms offsets), `text` (field text at the end of the burst), `burstStartMs`, `fieldKind`                                                                                                                                  | session |
| `streams/clipboard.jsonl`                                       | adds `text` and copy provenance: `aiSimilarity` (5-gram Jaccard to the last 3 AI outputs), `matchedTurnId`, `sourceChannel`, `targetField`                                                                                                                         | session |
| `streams/clicks`, `cursors`, `scrolls`, `visibility`            | add `tabId` and `clientSeq` (and `id` where useful)                                                                                                                                                                                                                | session |
| `derived/learning_events.jsonl`                                 | current version only, adds `id`, `detectionKey`, `sourceActionIds`, `sourceRefs`, `detail`, `computedValues`, `alternatives`, `evidenceClass`, `libraryHash`, `parameterHash`, `engineVersion`, `computedAt`                                                       | session |
| `derived/parse_runs.jsonl`                                      | every parse of the session (trigger, status, library and parameter hashes, detections)                                                                                                                                                                             | session |
| `derived/coverage.jsonl`                                        | active time explained by the rules, per library and parameter version                                                                                                                                                                                              | session |
| `derived/parameter_snapshots.jsonl`                             | the exact parameter values the session's events used, by hash                                                                                                                                                                                                      | session |
| `derived/library.jsonl`                                         | the library version and hash used, with the library content when the file on disk has that hash                                                                                                                                                                    | session |
| `quality/ingest_issues.jsonl`                                   | events refused, duplicated, dropped or overflowed on the way in                                                                                                                                                                                                    | session |
| `quality/capture_quality.jsonl`                                 | sequence gaps and out-of-order arrivals per stream and tab                                                                                                                                                                                                         | session |
| `interventions/ledger.jsonl`                                    | intervention decisions: learner launches, nudges shown or withheld, NO_ACTION with the reason                                                                                                                                                                      | session |
| `messages/llm_turns.jsonl`                                      | one row per Learning Assistant turn (context source, attempt before, time since last error, follow-up, model, latency, flags)                                                                                                                                      | session |
| `outcomes/knowledge_tests.jsonl`, `knowledge_test_scores.jsonl` | knowledge-test attempts in this session and their written-answer scores                                                                                                                                                                                            | session |
| `outcomes/efa_*.jsonl`                                          | EF battery: occasions, task runs, trials, answers, scores                                                                                                                                                                                                          | learner |
| `promptlab/runs.jsonl`                                          | Prompt Lab runs of this session                                                                                                                                                                                                                                    | session |
| `promptlab/versions`, `test_cases`, `test_results`, `ratings`   | the learner's Prompt Lab work                                                                                                                                                                                                                                      | learner |
| `lesson/slide_states.jsonl`                                     | the learner's saved lesson state per slide                                                                                                                                                                                                                         | learner |
| `notes/study_notes.jsonl`                                       | the learner's notes and highlights                                                                                                                                                                                                                                 | learner |

"Learner" scope means all of that learner's rows, as in v1 `kc/cards.jsonl` and `kc/attempts.jsonl`; analysis joins them to sessions by time or id.
