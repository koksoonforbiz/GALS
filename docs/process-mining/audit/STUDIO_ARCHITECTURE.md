### Re-import and code preservation (confirmed, with one exception)

- The importer deletes the `Session` row, which cascades to every FK table above, deletes the media folder, and re-inserts (`gals-studio/apps/studio-server/src/import/importer.ts:115-123`).
- Coding tables survive because they have no relation to `Session`: `Annotation` (`schema.prisma:373-398`; its only relations are to `Coder` and `CodebookVersion`, `:378`, `:381`), `WindowCoding` (`:456-480`), `UtteranceCoding` (`:485-502`), `SessionAoi` (`:426-438`), `SessionTrim` (`:443-448`), `ReliabilityRun` (`:414-421`), `Coder`, `CodebookVersion`. **Confirmed.**
- Exception: `CodingWindow` is FK-bound (`schema.prisma:362-371`) and is regenerated from the new manifest's `durationMs` with the deterministic id `${sessionId}:${index}` (`importer.ts:225-246`, `gals-studio/packages/shared/src/bundle/spec.ts:45-52`). `Annotation.windowId` is a plain string pointing at it. If a re-export changes `durationMs` or `baseWallClockMs` (commit `69893a8` changed how duration is computed, `tools/gals-export/src/export.ts:129-134`), window ids still match by index but may now cover different wall-clock spans, or no longer exist. Same risk for `WindowCoding.windowStartMs` (offset from base, `schema.prisma:460`) and `UtteranceCoding.refWallMs` (an utterance is identified by its timestamp, `schema.prisma:490`). See STU-14.
- `LearningEvent` is FK-bound and gets new autoincrement ids on each import (`schema.prisma:507-510`), so nothing durable can reference a Studio learning-event id today. See STU-02.

## 4. Importer flow (`gals-studio/apps/studio-server/src/import/importer.ts`)

1. `resolveBundleDir`: a `.zip` is stream-extracted to a temp dir (handles >2 GB), a single top folder is unwrapped (`:58-75`).
2. `validateBundle` (`gals-studio/packages/shared/src/bundle/validate.ts:49-169`): manifest zod schema with `bundleVersion: z.literal(1)` (`gals-studio/packages/shared/src/bundle/schemas.ts:12-26`), required files, sha256 per manifest entry, session.json, snapshot and webcam indexes, every present JSONL parsed and counted against `manifest.counts`. **Checksum mismatches are only warnings** (`validate.ts:82-93`), although the docblock says they are errors (`validate.ts:44-48`). The import stops only on structural errors (`importer.ts:105-108`).
3. Seed the default codebook once (`importer.ts:40-55`, `:113`).
4. Delete the session (cascade) and media, recreate folders (`:115-123`).
5. Insert `Session` from manifest + session.json (`:125-146`). `session.json.syncAnchor` (monotonic and server-receive ms) is parsed by the validator but not stored.
6. Copy snapshot html/jpg and insert `Snapshot` rows (`:148-185`); copy webcam files and insert `WebcamSegment` (`:187-212`).
7. Streams: for each key with a file listed in the manifest, a per-stream mapper inserts in batches of 2000 (`:20`, `:214-223`, mappers `:319-695`). A failing stream becomes a warning and the import still reports `ok: true` (`:220-222`, `:248`). No transaction wraps steps 4-9.
8. Coding windows: 20 s `CodingWindow` rows from base (`:225-246`).
9. On an exception, best-effort delete of the half-imported session (`:250-256`), temp cleanup (`:257-259`).

CLI: `npm -w @gals-studio/server run import -- '<glob>'` (`gals-studio/apps/studio-server/src/import/cli.ts`, `gals-studio/README.md:22-24`).

### 7.2 Replay components (`gals-studio/apps/studio-web/src/replay/`)

- `clock.ts`: `PlayheadStore` (`:17`), the single source of truth for replay time. State is `offsetMs` relative to `baseWallClockMs`; `currentAbsoluteMs = base + offsetMs` (`:48-50`); `seek(offsetMs)` clamps to `[0, durationMs]` and notifies (`:52-55`); `seekAbsolute(absoluteMs)` = `seek(absoluteMs - base)` (`:57-59`); `setConfig` re-clamps (`:28-31`); `play` drives a requestAnimationFrame loop scaled by `speed` (`:66-86`); React binds via `usePlayhead` = `useSyncExternalStore` (`:108-110`). `fmtWall` always formats in Asia/Singapore, ignoring `Session.timezone` (`:123-128`).
- `DomStage.tsx`: iframe of snapshot HTML (or the jpg when `showScreenshot`), scaled overlays for gaze, click ring, AOIs, plus an `overlay` slot (`:18-57`). A `trigger === 'cleanup'` snapshot renders "Screen recording paused here" with a reason and "Recording resumes at ..." (`:68-95`, text at `:87`) (verified). The reason text still says puzzles and knowledge tests "are not screen-recorded" (`:80-84`), which is stale after `acee9b6`: those pages now record in gentle mode (`apps/web/src/components/replayPause.ts:3-8`, `:19-24`). STU-22.
- `WebcamPanel.tsx`: picks the segment covering the playhead and sets `video.currentTime = (absoluteMs - seg.startWallMs)/1000` when drift > 0.25 s (`:9-25`).

### 7.3 Time base and seek

- Bundle anchor: `baseWallClockMs = min(session_sync_anchors.wallClockMs, first snapshot capturedAt, student_sessions.startedAt)` (`tools/gals-export/src/export.ts:117-123`), stored on `Session` (`gals-studio/apps/studio-server/prisma/schema.prisma:28`, `importer.ts:137`).

Each page owns its own store instance (`pages/Replay.tsx:35-37`, `pages/TimelineCoding.tsx:258-260`, `pages/WindowCoding.tsx:177-179`); there is no URL parameter or shared context to open a page at time t (no `useSearchParams` anywhere in `gals-studio/apps/studio-web/src`).
